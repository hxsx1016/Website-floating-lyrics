# 桌面歌词

Windows 桌面悬浮歌词。会识别系统当前正在播放的歌曲（网易云、QQ 音乐、Spotify、Edge/Chrome、系统媒体播放器等），并按进度同步歌词。

## 运行

双击 `DesktopLyrics.exe`。

1. 用任意播放器开始放歌。
2. 桌面歌词会显示歌名、歌手、播放来源。
3. 酷狗音乐会单独识别（它通常不走系统媒体控件）：读窗口标题 / 配置，并用声音判断播放或暂停。
   酷狗不提供实时进度。拖进度条后，可点桌面歌词底部进度条对齐；暂停时也会读取酷狗保存的位置。
4. 程序会先在 `lyrics` 和酷狗歌词目录里找本地 `.lrc` / `.krc`；找不到再联网检索（酷狗 → lrclib → 网易云 → QQ 音乐）。
4. 检索到的歌词会保存到 `lyrics`，下次同一首歌直接用本地缓存。

也可以把 `.lrc` 直接拖到窗口上。右键托盘可关闭「自动检索」，或点「立即检索当前歌曲」。

## 使用说明

播放器需要把正在播放的信息发给 Windows（任务栏 / 音量面板里能看到歌名，就能被识别）。

部分软件需要在设置里打开类似：

- 网易云音乐：允许被系统媒体控件控制 / 在系统中显示
- QQ 音乐：类似的系统媒体信息选项

浏览器放歌时，页面需要是当前标签页，并且网站支持媒体会话。

### 操作

| 操作 | 说明 |
| --- | --- |
| 拖动窗口 | 按住歌词区域拖动 |
| 右下角拉伸 | 调整窗口大小 |
| 滚轮 | 调整字号 |
| 双击 | 播放 / 暂停（跟随系统时控制播放器） |
| 拖入 `.lrc` | 加载歌词 |
| 控制台 | 独立窗口：播放、漂浮、锁定、字号、颜色、检索 |
| 托盘左键 | 显示控制台 |
| 托盘右键 | 跟随系统、打开歌词库、锁定、改颜色、退出 |
| `Ctrl + 空格` | 播放 / 暂停 |
| `Ctrl + ← / →` | 上一句 / 下一句 |
| `Ctrl + L` | 锁定（点击穿透，不挡桌面） |
| `Ctrl + F` | 全屏漂浮歌词（类似浮动字幕，点击可穿透） |
| `Ctrl + P` | 显示 / 隐藏控制台 |
| `Ctrl + O` | 打开歌词文件 |

启动后会单独弹出控制台窗口，歌词 overlay 只负责显示。全屏漂浮时鼠标会穿透歌词，用控制台或 `Ctrl+F` / `Ctrl+P` 操作。关闭控制台不会退出程序，点托盘或再按 `Ctrl+P` 即可重新打开。

## 编译

```bat
build.bat
```

或：

```bat
cmake -S . -B build
cmake --build build --config Release
```

需要 Visual Studio（MSVC）C++ 桌面开发组件。
